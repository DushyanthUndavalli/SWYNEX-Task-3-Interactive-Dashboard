# Student Performance Interactive Dashboard

## Internship
SWYNEX Internship – Task 3

## Project Overview
This project presents an interactive student performance dashboard built using Microsoft Power BI.

## Dataset
Students Performance in Exams dataset.

## Tools Used
- Microsoft Power BI – Dashboard creation and visualization
- CSV – Dataset storage
- Power Query – Data preparation

## Dashboard Features
- Total Students
- Average Math Score
- Average Reading Score
- Average Writing Score
- Performance analysis by gender
- Performance analysis by parental education
- Performance analysis by lunch type
- Test preparation course analysis
- Interactive slicers for filtering data

## Files Included
- Power BI dashboard (.pbix)
- CSV dataset

## Objective
To analyze student performance and present meaningful insights through interactive visualizations.
